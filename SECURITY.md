# Security Policy

## Supported Versions

Security updates are applied to the latest active release and the `main` branch of each repository.

| Version | Supported |
| ------- | --------- |
| Latest release / `main` | Yes |
| Older versions | No |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly rather than opening a public GitHub issue.

- **Email:** halukcansarioz19@gmail.com
- **Subject:** `[SECURITY] <Repository Name> - <Brief Summary>`

Please include in your report:
1. A clear description of the vulnerability and its potential impact.
2. Steps to reproduce the issue or a proof-of-concept.
3. Any affected versions, configurations, or suggested fixes if available.

We aim to acknowledge receipt of your report within 48 hours and will coordinate with you on remediation and disclosure.
