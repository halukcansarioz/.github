# Contributing Guidelines

Thank you for your interest in contributing! Please follow the workflow below to keep contributions consistent and easy to review.

## Contribution Workflow

1. **Fork the repository**
   Create your own fork of the target repository on GitHub and clone it locally.

2. **Create a branch**
   Branch off from `main` using a descriptive name (e.g., `feat/add-login`, `fix/typo-readme`):
   ```bash
   git checkout -b feat/your-feature-name
   ```

3. **Make changes & commit**
   Keep commits focused and write clear, concise commit messages:
   ```bash
   git add .
   git commit -m "feat: brief description of your change"
   ```

4. **Push & open a Pull Request**
   Push your branch to your fork and open a Pull Request against the `main` branch:
   ```bash
   git push origin feat/your-feature-name
   ```
   Fill out the Pull Request template, link any related issues, and ensure all checks/tests pass before requesting review.
